# Requirements Document: AI-экосистема T&D ИТ-кластера "Газпром Нефти"

**Версия:** 1.0  
**Дата:** 2025-01-15  
**Автор:** Product Architecture Team  
**Статус:** Draft  
**Проект:** AI-powered Training & Development Platform (T&D Ecosystem)

---

## 1. Общее описание

### 1.1 Цель проекта

Разработка единой корпоративной экосистемы обучения и развития (T&D Ecosystem) на базе универсальных AI-агентов для ИТ-кластера ПАО "Газпром Нефть". Система обеспечивает персонализированный онбординг, непрерывное обучение, карьерное планирование, коммуникацию и аналитику для более чем 5000 сотрудников, распределенных по 47 городам и 240+ площадкам.

Ключевая цель — создание AI-first платформы, где каждый сотрудник имеет персонального AI-ассистента, который сопровождает его на всех этапах жизненного цикла в компании: от первого рабочего дня до формирования карьерной траектории и планирования преемственности.

### 1.2 Область применения

Система покрывает следующие бизнес-процессы:

| # | Процесс | Описание | Затронутые роли |
|---|---------|----------|-----------------|
| 1 | Онбординг новых сотрудников | Адаптация сотрудников в первые 90-180 дней | HR, руководители, новые сотрудники |
| 2 | Непрерывное обучение | Повышение квалификации, переквалификация, микрообучение | Все сотрудники |
| 3 | Управление компетенциями | Ассессмент, грейдинг, развитие компетенций | HR, руководители, сотрудники |
| 4 | Карьерное планирование | Траектории развития, преемственность кадров | HR, руководители, сотрудники |
| 5 | Корпоративные коммуникации | Планирование встреч, координация, нетворкинг | Все сотрудники |
| 6 | Аналитика и отчетность | Мониторинг прогресса, предиктивная аналитика | HR, топ-менеджмент, руководители |

**География:** 47 городов РФ, 240+ площадок, 50 центров компетенций.

### 1.3 Целевая аудитория

#### Первичные пользователи (ежедневное использование)
- **Сотрудники ИТ-кластера** — 5000+ человек, различные грейды (Junior → Lead → Principal)
- **Руководители команд** — 300+ человек, контроль развития подчиненных
- **HR-партнеры** — 50+ человек, управление процессами T&D

#### Вторичные пользователи (периодическое использование)
- **HR-директора и топ-менеджмент** — стратегическая аналитика, отчетность
- **Администраторы платформы** — настройка и поддержка системы
- **Авторы контента** — создание и публикация учебных материалов

#### Системные акторы
- **AI-агенты** — 5 типов универсальных агентов, работающих автономно
- **Внешние системы** — HR-системы, корпоративные сервисы, LMS

### 1.4 Ограничения и допущения

#### Ограничения

| ID | Ограничение | Описание | Влияние |
|----|-------------|----------|---------|
| C1 | Инфраструктурные | Размещение в on-premise или private cloud (Газпром Нефть) | Невозможно использовать публичные SaaS для чувствительных данных |
| C2 | Регуляторные | Соответствие 152-ФЗ "О персональных данных" | Обработка ПД сотрудников только на территории РФ |
| C3 | Безопасность | Защита коммерческой тайны и внутренних данных | Строгий контроль доступа, аудит, шифрование |
| C4 | Интеграционные | Интеграция с существующим ИТ-ландшафтом | Необходимость адаптеров для legacy-систем |
| C5 | Организационные | 50 центров компетенций с разными процессами | Требуется гибкая настройка под каждый ЦК |

#### Допущения

| ID | Допущение | Обоснование |
|----|-----------|-------------|
| A1 | Наличие корпоративного LLM или доступ к нему | Предполагается использование on-premise LLM (GigaChat Enterprise, YandexGPT Бизнес или open-source моделей) |
| A2 | Данные о сотрудниках доступны из HR-систем | Интеграция с SAP HCM / 1С:ЗУП / внутренними системами |
| A3 | Наличие корпоративной инфраструктуры Kubernetes | Стандарт для новых проектов в Газпром Нефти |
| A4 | Существующая библиотека контента может быть экспортирована | Возможность ETL из текущих LMS |
| A5 | Единая система аутентификации (Active Directory) | Централизованное управление доступом |

## 2. Функциональные требования

### 2.1 Модуль AI-онбординга (AI Onboarding Module)

**Цель:** Автоматизация и персонализация адаптации новых сотрудников с использованием AI-наставника.

| ON-03 | Этапы онбординга | Must Have | Поддержка 4 этапов: Предвход (до 1-го дня), Первая неделя, Первый месяц, Первые 3 месяца |

## 5. Критерии приемки

### 5.1 Функциональные критерии

- [ ] **ON-ALL** Все функции модуля AI-онбординга работают корректно: план адаптации генерируется, AI-наставник отвечает на вопросы, прогресс отслеживается, курсы назначаются автоматически
- [ ] **LD-ALL** Модуль обучения: каталог доступен, AI-поиск возвращает релевантные результаты (precision@5 > 80%), рекомендации персонализированы, IDP генерируется и отслеживается
- [ ] **CT-ALL** Модуль карьерных треков: визуализация работает, AI рекомендует пути развития, связь с оценками функционирует
- [ ] **CM-ALL** Модуль коммуникаций: единое окно работает, интеграция с календарем реализована, AI планирует встречи корректно
- [ ] **AN-ALL** Модуль аналитики: дашборды отображают данные, отчеты формируются, прогнозы строятся

### 5.2 AI-качество

- [ ] **AI-ACC-01** Точность ответов AI-наставника > 90% (оценка экспертов на тестовой выборке из 500 вопросов)
- [ ] **AI-ACC-02** Релевантность рекомендаций курсов: precision@5 > 80%, recall@20 > 70%
- [ ] **AI-ACC-03** Точность планирования встреч (подбор слота, который устраивает всех) > 95%
- [ ] **AI-ACC-04** Точность прогноза оттока: ROC-AUC > 0.75
- [ ] **AI-LAT-01** Среднее время ответа AI-агента < 2 секунд (p95 < 5 секунд)

### 5.3 Производительность

- [ ] **PERF-LD** Нагрузочное тестирование пройдено: 5000 concurrent users, 1000 RPS, время отклика p95 < 2 сек
- [ ] **PERF-AI** AI-инференс: 100 concurrent запросов к LLM, среднее время < 3 сек
- [ ] **PERF-DB** Запросы к БД: p95 < 100 мс для 95% запросов

### 5.4 Безопасность

- [ ] **SEC-AUDIT** Прохождение security audit: отсутствие критических и высоких уязвимостей
- [ ] **SEC-COMPLIANCE** Подтверждение соответствия 152-ФЗ (заключение DPO)
- [ ] **SEC-PENTEST** Прохождение пентеста: отсутствие критических уязвимостей
- [ ] **SEC-LLM** Проверка защиты от prompt injection и data leakage: 0 успешных атак из 1000

### 5.5 Пользовательское тестирование

- [ ] **UX-ONBOARD** Юзабилити-тестирование онбординга: 15+ сотрудников, успешность > 85%
- [ ] **UX-OVERALL** Общая оценка NPS > 40 (опрос 200+ сотрудников)
- [ ] **UX-ACCESS** Accessibility: соответствие WCAG 2.1 Level AA

### 5.6 Интеграции

- [ ] **INT-AD** Интеграция с Active Directory: синхронизация пользователей, SSO работает
- [ ] **INT-HR** Интеграция с HR-системой: данные синхронизируются, оргструктура актуальна
- [ ] **INT-CAL** Интеграция с календарем: события создаются, обновляются, удаляются
